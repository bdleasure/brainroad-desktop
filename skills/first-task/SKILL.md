---
name: first-task
description: Check this BrainRoad setup with a small local job (create a file, use the visible browser, save and re-read a receipt) using only made-up data, no accounts and no outside websites.
---

Use this when the person asks to check that BrainRoad works on this computer.

1. Say which computer the tools are running on (computer name and operating system from
   the terminal). If it is a remote or cloud gateway rather than the computer the person
   is using, say so before continuing.
2. In a new folder named `brainroad-check-<date-time>` under the person's Documents
   folder (or the current workspace if Documents is unavailable), write `check.html`
   containing the heading `BrainRoad local check`, two number inputs with values 7 and 5,
   an **Add** button, and an output element. Use only local HTML and JavaScript: no
   network requests, analytics or accounts.
3. Open that file in the visible browser, wait for it to load, click **Add**, then read
   the output back. It must say 12.
4. Write `receipt.txt` beside it with the observed result and the time, then read the
   file back with the file tool.
5. Report each part separately: file written, browser opened, button clicked, result read
   back, receipt re-read. Mark any failed part as failed or blocked. Give the folder path.
6. Ask whether they saw the browser window open; do not assume it was visible from the
   tool result.

This checks one browser and file workflow. It does not prove repairs, coding, phone
access or every operating-system permission. Leave the folder for the person to look at;
offer to delete it. Then ask what they would like help with on this computer.
